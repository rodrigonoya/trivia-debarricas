# Trivia De Barricas

Trivia web estática para De Barricas, pensada para GitHub Pages y para ser integrada luego en otra aplicación.

## Edición de contenido

- `questions.json`: preguntas, opciones y respuesta correcta.
- `config.json`: cantidad de preguntas, textos de feedback, descuentos y mensajes finales.
- `styles.css`: colores, tamaños, espaciados y animaciones.

## Publicación

No requiere servidor ni base de datos. GitHub Pages puede publicar directamente estos archivos.
